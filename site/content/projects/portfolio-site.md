## 기간과 진행 상태 {#period}

- 2026년 10월 26일 ~ 10월 31일 (초급프로젝트 과제 1, 개인 수행)
- 사이트 배포 완료

## 목적 {#purpose}

본인 소개와 활동을 한곳에서 보여 주고, 수정 후 push하면 자동으로 다시 배포되는 사이트를 만드는 것이 목표였습니다.

## 내가 맡은 역할 {#role}

개인 과제로 테마 선택, 설정, 글 작성, 점검을 직접 했습니다. 설정과 점검에는 AI(Claude)의 도움을 받았고, 반영 여부는 실제 화면에서 확인한 뒤 정했습니다.

## 수행 과정과 선택 이유 {#process}

1. PaperMod 테마를 골랐습니다. → 프로필형 홈 화면이 있고 추가 빌드 도구 없이 배포할 수 있어서입니다.
2. 메뉴·소개·활동 페이지를 구성했습니다.
3. 여러 화면 폭과 키보드로 점검하고, 찾은 문제(초점 표시가 잘 안 보임 등)를 고쳤습니다.

- **배운 점:** 눈으로 보기에 멀쩡해도 키보드로 쓰면 불편한 곳이 있어, 화면과 키보드 점검을 같이 해야 한다는 것을 배웠습니다.
- **다음 개선:** 다른 브라우저에서도 같은 점검을 해 볼 계획입니다.
