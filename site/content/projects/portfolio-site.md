## 기간과 진행 상태 {#period}

- **기간**: 2026년 10월 26일 ~ 10월 31일 (초급프로젝트 과제 1)
- **상태**: 사이트 배포 완료, 마감 전까지 점검과 개선 진행
- **개인 수행**

## 목적 {#purpose}

본인 소개와 실제 활동을 한곳에서 보여 주는 사이트를 만들고, **수정 내용을 push하기만 하면 자동으로 다시 배포되는 구조**를 갖추는 것이 목표였습니다. 기능을 많이 넣기보다 모든 링크·화면 폭·키보드 조작이 실제로 동작하는지 확인하는 데 집중했습니다.

## 내가 맡은 역할 {#role}

개인 과제라 테마 선택, 설정, 글 작성, 점검, 커밋을 모두 직접 했습니다. 설정 파일 작성과 점검에는 AI(Claude)의 도움을 받았고, 제안을 채택할지는 실제 화면에서 확인한 뒤 정했습니다.

## 수행 과정과 선택 이유 {#process}

1. **테마 선택 — PaperMod**  
   프로필형 홈 화면이 있어 자기소개를 바로 보여 줄 수 있고, 추가 빌드 도구(npm) 없이 Hugo만으로 빌드되어 배포 실패 위험이 적어서 골랐습니다.

2. **Download ZIP → 준비 스크립트 → Git 연결**  
   Fork 대신 ZIP으로 받아, 원본 테마의 커밋 이력이 섞이지 않고 처음부터 내 작업 이력만 남도록 했습니다.

3. **설정과 페이지 구성**  
   언어를 한국어(`ko`)로, 홈을 프로필 모드로 바꾸고 상단 메뉴(소개·활동·GitHub)를 만들었습니다. 섹션마다 앵커(`#interests` 등)를 붙여 주소로 바로 열 수 있게 했습니다.

4. **점검 후 수정**  
   1440·768·390px 화면과 Tab 키 이동을 점검해, 초점 표시가 0.8px로 거의 보이지 않는 문제와 아이콘만 있는 GitHub 링크에 이름이 없는 문제를 찾아 고쳤습니다. 테마 원본은 고치지 않고 `site/` 아래에 덮어쓰는 파일을 만들어, 테마를 업데이트해도 충돌하지 않게 했습니다.

## 배운 점과 개선 방향 {#lessons}

**배운 점**
- 수업 영상과 같은 명령을 입력해도 내 PC의 상태에 따라 결과가 달랐습니다. 예전에 저장된 GitHub 로그인 정보가 만료되어 push가 실패했고, 저장 방식을 확인한 뒤 저장된 정보를 지우고 다시 로그인해 해결했습니다.
- 눈으로 보기에 멀쩡해도 키보드로 쓰면 불편한 곳이 있었습니다. 화면 확인에 더해 Tab 키 점검을 같이 해야 한다는 것을 배웠습니다.

**다음 개선**
